# 予約キュー

ここに置いた `.txt` が、書いた日時に Threads へ自動で投稿されます（main ブランチにあるもの＝承認済み）。
投稿が済んだファイルは `posted/` に移ります。取りやめたいときは、時刻の前にファイルを消せばOKです。

ファイル名は `2026-10-01_2130_夜.txt` のように日付・時刻・枠にしておくと並びが分かりやすいです。

```
date: 2026-10-01
time: 21:30
slot: 夜
type: 感情爆発
---
あのさーー!?
既読3時間放置しといて
「ごめん寝てた」は無理あるって🫠

目標：既読つけたら5分以内に返せる男と付き合う
```

- `slot` は 朝/昼/夜、`type` は 分析メモと同じ型（感情爆発・恋愛あるある・男磨き・二択・問いかけ・日常写真・価値観・伏線）
- `---` の下は Threads にそのまま出る本文。500文字まで
- リンク（http・note.com など）が入っていると投稿しません（フォロワー300〜500まではリンクなしの方針）。フェーズ2で解禁するときはリポジトリ変数 `ALLOW_LINKS` を `true` に
- 予定時刻から90分過ぎても出せなかったものは投稿せず残します（古い投稿がずれて出ないように）
- 写真つき投稿はまだ自動化していないので、日常写真は手で投稿してください
